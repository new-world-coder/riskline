How it works

          
Describe the system. Read the clause.

          

            One contract for CLI and HTTP API. Distribution model borrows from OPA and
            Trivy — single binary, CI-friendly.

              01
              
    Author a description
    
              
    
                YAML or JSON: purpose, data types, deployment context, autonomy, who it
                affects — plus optional Article 5 flags.

  2. 
              02
              
    Run the classifier
    
              
    
                riskline-cli system.yaml offline, or
                POST /v1/classify against the thin API.

    Get an auditable result

Why this exists

          
Built for pipelines, not portals

          

            Most AI governance tools want you inside a dashboard. Engineering teams
            already live in CI and the terminal.
          

          
    
            
  • 
              Deterministic
              
    Versioned JSON ruleset
    
              
    
                Every result cites which rule fired. Diff the ruleset. Pin
                ruleset_version in CI.
              
    
            
    • 
            
  • 
              Offline-first
              
    Nothing leaves your machine
    
              
    
                The CLI reads local files only. It does not phone home. See PRIVACY.md.
              
    
            
    • 
            
  • 
              CI-native
              
    Single Go binary
    
              
    
                Install once, run in GitHub Actions or pre-commit. OpenAPI contract
                included for the API surface.
              
    
            
    • 
            
  • 
              Honest
              
    Advisory, not a verdict
    
              
    
                Judgment calls are surfaced. Misclassification reports are the
                validation loop — not marketing claims.
              
    
            
    • 
          

        

      


      

        

          
Scope

          
What you should not expect yet

          
    
            
  • Full Annex III coverage (v1 prioritises recruitment, employment, credit, biometrics, law-enforcement risk scoring, plus a few adjacent cases)
    • 
            
  • Enterprise gloss, customer logos, or published prices
    • 
            
  • Hosted multi-tenant SaaS — early access only via GitHub Discussions
    • 
            
  • NIST / ISO mappings, dashboards, or evidence packs
    • 
          

          

            This classification is an advisory tool based on a versioned ruleset. It is
            not legal advice and is not a substitute for qualified counsel or a formal
            conformity assessment.
