RiskLine

Offline EU AI Act risk classification — CLI & API

v0.1.0-alpha · Apache 2.0
github.com/new-world-coder/riskline

Open-source classifier for AI systems under the EU AI Act. You describe a system; RiskLine returns prohibited / high-risk / limited-risk / minimal-risk with clause references — from a versioned JSON ruleset, not an LLM.

Built for engineering teams who live in CI and the terminal, not a compliance portal.

Who it’s for

  • Engineers putting AI systems into pipelines
  • Teams inventorying systems for EU AI Act readiness
  • Anyone who needs offline, diffable, auditable classification

How it works

  1. Author a YAML/JSON description (purpose, data, context, autonomy, population).
  2. Run riskline-cli or POST /v1/classify.
  3. Read tier, matched rules (article/annex), rationale, controls, judgment calls.

Quick start

go install github.com/new-world-coder/riskline/cmd/riskline-cli@v0.1.0-alpha
riskline-cli examples/curl/hiring-assist.yaml
riskline-cli --json examples/curl/hiring-assist.yaml

Features

  • Deterministic & auditable Versioned ruleset; every hit cites a clause.
  • Offline-first CLI does not phone home.
  • CI-friendly Single Go binary (OPA/Trivy-style).
  • CLI + HTTP API Shared contract; OpenAPI included.
  • Apache 2.0 Misclassification reports welcome.

Sample — Hiring Assist

System:           Hiring Assist
Risk tier:        high_risk
Ruleset:          eu-ai-act-2024-v0.1.0

Matched rules
high-risk-recruitment  high_risk  Annex III (4)(a)
